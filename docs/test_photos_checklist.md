# Чек-лист тестових фото

Знімай телефоном, звичайна роздільність. Назви файлів — як у колонці «Файл»,
поклади все в `samples/`. Вимога завдання — 5–10 прикладів; тут 12 із запасом.

## Вдалі (очікуємо успіх)

| Файл | Що зняти | Навіщо |
|------|----------|--------|
| `01_a4_dark_top.jpg` | Аркуш A4 з текстом на темному столі, зверху | еталонний випадок |
| `02_a4_dark_angle.jpg` | Те саме, під кутом ~30–45° | перевірка корекції перспективи |
| `03_a4_rotated.jpg` | Аркуш повернутий на ~45° у кадрі | порядок кутів |
| `04_receipt.jpg` | Чек на темному фоні | вузький витягнутий документ |
| `05_card.jpg` | Візитка / банківська картка (номер закрити!) | малий об'єкт |
| `06_book_page.jpg` | Сторінка/обкладинка зошита на столі | кольоровий документ |

## Проблемні (очікуємо помилки — це теж потрібно для звіту)

| Файл | Що зняти | Очікувана проблема |
|------|----------|--------------------|
| `07_shadow.jpg` | Аркуш, на який падає тінь від руки/телефона | нерівна бінаризація |
| `08_low_light.jpg` | Аркуш при слабкому світлі | шум, слабкі краї |
| `09_white_on_white.jpg` | Білий аркуш на білому/світлому столі | контур не знайдено |
| `10_folded_corner.jpg` | Аркуш із загнутим кутом | не 4 вершини |
| `11_cut_off.jpg` | Один кут аркуша поза кадром | неповний контур |
| `12_cluttered.jpg` | Аркуш серед інших предметів (ручки, клавіатура, книжки) | хибний контур |

## Поради

- Не використовуй вбудований «сканер документів» телефона — потрібне сире фото.
- Бажано, щоб на аркуші був текст — так видно якість бінаризації.
- Можна додати 1–2 фото з інтернету (вільна ліцензія) для різноманітності.
